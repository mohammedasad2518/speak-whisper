# 📖 About

**Speak-Whisper** is an AI-powered speech processing application that enables users to convert spoken audio into text using modern speech recognition models.

The project leverages state-of-the-art speech AI technology to provide accurate transcription, multilingual support, and an intuitive user experience for voice-based applications. Whisper models are widely used for multilingual speech recognition and translation tasks. :contentReference[oaicite:0]{index=0}

# 🚀 Installation

Clone the repository

```bash
git clone https://github.com/mohammedasad2518/speak-whisper.git
```

Move into the project

```bash
cd speak-whisper
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
python app.py
```
